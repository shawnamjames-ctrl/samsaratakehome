# Review package

Start with the interactive site, then use these two concise documents for the executive
and methodological readouts:

1. [CPO memo](Samsara_CPO_Memo.pdf) - the three-page thematic story, product
   recommendations, and additional research questions.

   challenge standard, analytical limits, and operating model.

Both PDFs are also linked from the interactive site. They contain the same approved
analytical release used by the static Overview, Analysis, and Method pages.
