# Technical appendix

This folder contains the optional supporting materials behind the case study. The final
review package remains in [`../deliverables/`](../deliverables/), and the finished
interactive project is available on [GitHub Pages](https://shawnamjames-ctrl.github.io/samsaratakehome/).

## What is here

- `public-data/` — privacy-safe evidence and approved analytical releases
- `content/` — approved narrative content used by the project
- `site-src/` and `docs/` — source and published versions of the interactive experience
- `config/` and `schemas/` — monitoring definitions and data-quality rules
- `pipeline/` and `tools/` — collection, analysis, publishing, and validation logic
- `tests/` — failure handling and contract checks
- `OPERATIONS.md`, `DATA_POLICY.md`, and `REPOSITORY_MAP.md` — detailed operating,
  privacy, and repository documentation

Raw review text, reviewer names, credentials, and private operational data are excluded
from this public repository.
